# Tienda Online

Este proyecto es una interfaz de tienda en línea, desarrollada utilizando HTML5, CSS3 y el framework Bootstrap 5.

## Pasos de Creación

A continuación se describen los pasos que se siguieron para la creación de este proyecto:

1. **Estructura Base:**
   - Creación del archivo principal `index.html`.
   - Definición de la estructura básica del documento HTML5.
   - Configuración de las etiquetas `<meta>` para asegurar la responsividad en dispositivos móviles.

2. **Integración de Dependencias Externas (CDN):**
   - **Tipografía:** Se enlazó la fuente moderna "Outfit" desde Google Fonts para mejorar la estética del sitio.
   - **Framework CSS:** Se integró Bootstrap 5 para agilizar el diseño, el uso de grillas (grids) y componentes responsivos.
   - **Iconografía:** Se añadieron los Bootstrap Icons para los botones de carrito, menús, etc.

3. **Definición de Estilos Personalizados (CSS):**
   - Dentro de la etiqueta `<style>`, se establecieron reglas globales (tipografía, colores de fondo y texto).
   - Se diseñó un aspecto para componentes específicos como la barra de navegación (Navbar oscuro) y el carrusel principal.

4. **Maquetación de la Interfaz (HTML):**
   - **Barra de Navegación (Navbar):** Creación de un menú superior responsivo con enlaces y opciones de tienda.
   - **Banner/Carrusel Hero:** Implementación de una sección destacada con imágenes usando el componente Carousel de Bootstrap.
   - **Catálogo de Productos:** Desarrollo de una cuadrícula mostrando tarjetas (`cards`) de productos con sus respectivas imágenes, descripciones, precios y botones de compra.


En Visual Studio Code, se recomienda usar la extensión **Live Server** para ver los cambios en tiempo real a medida que se edita el código.
